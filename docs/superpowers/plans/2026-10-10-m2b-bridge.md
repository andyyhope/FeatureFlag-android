# M2b Bridge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give a host app an opt-in ContentProvider bridge, and give a companion app the client side of it:
- `featureflag-bridge` with `FlagBridgeProvider`, its signature permission and its manifest entries (B1);
- `FlagBridgeClient.connect()` and `send()`, `FlagBridgeConnection` and `FlagBridgeException` (B2);
- `FlagBridgeSource`, a live, cached view of the host's companion overrides (B3);
- an instrumented suite that runs the provider in a second process on the `Pixel_7` emulator, and checks core's number descriptions on ART (B4).

**Architecture:** The provider finds everything by convention: the schema from the file `publishSchema(context)` writes, the overrides through `SharedPreferencesSource.companion(context)`, and signals through `FlagSignalChannel.host`. It answers four `call()` methods (`hello`, `overrides`, `apply`, `signal`) and serves the schema through `openFile`. It waits once for the main looper before its first answer, so a cold-started host has finished `Application.onCreate`. The client acquires an unstable provider client per operation, closes it afterwards and retries once on `DeadObjectException`. It runs blocking binder calls in a detached `async`, so a timeout returns on time even while the call is still stuck in the host. `FlagBridgeSource` keeps an immutable map, refreshes it from a `ContentObserver` served by its own `HandlerThread`, and writes through one `apply` call per `setBoxes`.

**Tech Stack:** As the M2 overview: AGP 9.1.1 with built-in Kotlin, Kotlin 2.2.10, compileSdk 36 / minSdk 26, kotlinx-coroutines 1.10.2, JUnit 4.13.2 + kotlin-test-junit, Turbine 1.2.1, Robolectric 4.16, AndroidX Test (core 1.7.0, runner 1.7.0, ext-junit 1.3.0), detekt 1.23.8.

**Contract:** [`2026-10-10-m2-overview.md`](2026-10-10-m2-overview.md). Every public name and signature below is the contract's. Where this plan had to choose something the contract leaves open, or found the contract wrong, it says so under "Contract issues found" at the end.

**Spec:** [`docs/superpowers/specs/2026-10-08-android-parity-design.md`](../specs/2026-10-08-android-parity-design.md), "Bridge (M2)", "Signals (M2)" and "Spike S6 findings".

## Review Focus

The overview's five Review Focus items, and where this plan pins each one:

1. **A payload larger than a binder transaction.**
   - Reading: the provider answers `STATUS_TOO_LARGE` with `KEY_SIZE`. Pinned by B1 `overridesLargerThanTheLimitAreRefusedNotThrown`. B3 `refreshingOverridesTooLargeToCarryThrowsTooLarge` maps it to `FlagBridgeException.TooLarge`.
   - Writing: `FlagBridgeSource.setBoxes` throws `TooLarge` before any call. Pinned by B3 `writingMoreThanTheLimitFailsBeforeSending`, which also checks the host saw no `apply`.
2. **The store holds a foreign or mistyped value.** B1 `aStoredValueTheSchemaRejectsIsLeftOutOfOverrides` stores a string outside an enum's cases, a string under an `Int` flag and a NaN under a `Float` flag, and expects only the valid override back. B1 `applyOverwritesAValueStoredWithAnotherType` covers "an `apply` overwrites it". B1 `aNonFiniteNumberIsRejectedNotThrown` covers the converse: an `apply` whose `-1e400` passes strict import but cannot be stored is answered `STATUS_REJECTED`, and nothing is written.
3. **The host never published.** B1 `everyMethodAnswersNotPublishedWithoutASchema` (`overrides` and `apply` answer `STATUS_NOT_PUBLISHED`, nothing is written, `hello`, `signal` and `openFile` still answer without crashing). B2 `aHostWithoutASchemaIsNotPublished`. B3 `writingToAHostThatNeverPublishedThrowsNotPublished` and `refreshingAHostThatNeverPublishedThrowsNotPublished`.
4. **A suffixed application id.** B2 `hostNotFoundNamesThePackageAndTheSuffixHint` asks for `com.example.host.debug` while only `com.example.host` is installed, and checks the whole message.
5. **The host process dies mid-session.** B4 `aSourceSurvivesTheHostProcessDying` kills the `:host` pid under a held `FlagBridgeSource`: its `ContentObserver` still fires for a write that cold-starts a new host, and its own next write succeeds. B4 `aCallTheHostDiesDuringIsRetriedOnceOnAFreshHost` kills the host *during* a call, which is the real `DeadObjectException` path; B2 pins the same retry under Robolectric.

Three more conditions this plan pins because S6 measured them:

6. **A cold host's first call arrives mid-`Application.onCreate`.** B1 pins the barrier's mechanics under Robolectric (`theFirstCallFromAnotherThreadWaitsForTheMainLooper`, `afterTheFirstAnswerCallsDoNotWaitAgain`, `aMainLooperThatNeverRunsDelaysTheFirstAnswerOnlyUntilTheBound`). B4 `aSignalToAColdHostWaitsForItsApplicationToStart` pins it on a device. B4's test Application sleeps before it publishes and registers observers, so without the barrier every first call fails.
7. **A caller without the permission.** B1 `aCallerWithoutThePermissionIsRefused` pins the provider's own `enforceCallingPermission`. B2 `aRefusedAcquireIsPermissionDenied` and `aProviderThatRefusesTheCallerIsPermissionDenied` pin the client's mapping of both refusals.
8. **A host that hangs.** B2 `aHostThatDoesNotAnswerInTimeIsUnresponsive` and `aSignalThatOutlivesItsTimeoutIsFalse` stall the fake host and check that the answer comes at the timeout (under 2 s for a 200 ms timeout), not when the stuck call ends.

- **`FlagSignalChannel.host` (A6):** `deliver` called on the main thread (the Robolectric test thread) runs the handlers inline. Called from a binder thread, it runs them on the main looper and, on timeout, withdraws the queued handlers and returns false. A handler that throws counts as not handled.
- **Core:** `FlagDefaultComparison`'s public description is its `toString()`; there is no `description` property (see "Contract issues found").

```kotlin
import android.content.ContentProvider
import android.content.ContentValues

import android.content.SharedPreferences

import android.os.Bundle
import android.os.Handler

import com.andyyhope.featureflag.android.signals.FlagSignalChannel
import com.andyyhope.featureflag.android.sources.SharedPreferencesSource
import com.andyyhope.featureflag.errors.FlagException
import com.andyyhope.featureflag.errors.FlagImportException

import com.andyyhope.featureflag.schema.FlagSchema
import com.andyyhope.featureflag.transport.FlagPayload
import com.andyyhope.featureflag.values.FlagKey
import com.andyyhope.featureflag.values.FlagValueBox
import java.io.File
import java.io.FileNotFoundException
import java.util.concurrent.CountDownLatch
import java.util.concurrent.TimeUnit
import kotlin.time.Duration
import kotlin.time.Duration.Companion.seconds

/**
 * Lets a companion app signed with the host's key read the host's schema, read and write its
 * companion overrides, observe them, and send it signals.
 *
 * Merged into the host by depending on `featureflag-bridge`. It needs no registration: it serves
 * the schema `publishSchema(context)` writes, the overrides in the file
 * [SharedPreferencesSource.companion] reads, and the signals [FlagSignalChannel.host] delivers.
 */
public class FlagBridgeProvider : ContentProvider() {

    private lateinit var source: SharedPreferencesSource
    private lateinit var preferences: SharedPreferences
    private lateinit var overridesUri: Uri

    // Strongly held: SharedPreferences keeps its listeners weakly.
    private val listener = SharedPreferences.OnSharedPreferenceChangeListener { _, _ ->
        context?.contentResolver?.notifyChange(overridesUri, null)
    }

    @Volatile
    private var started = false

    /** How long the first answer waits for the main looper. Tests shorten it. */
    internal var startupTimeout: Duration = STARTUP_TIMEOUT

    override fun onCreate(): Boolean {
        val context = checkNotNull(context)
        source = SharedPreferencesSource.companion(context)
        preferences = context.getSharedPreferences(FlagBridgeContract.PREFERENCES_NAME, Context.MODE_PRIVATE)
        preferences.registerOnSharedPreferenceChangeListener(listener)
        overridesUri = FlagBridgeContract.overridesUri(context.packageName)
        return true
    }

    override fun call(method: String, arg: String?, extras: Bundle?): Bundle {
        val context = checkNotNull(context)
        // The manifest permission already keeps other apps from opening the provider; this is defence in depth.
        context.enforceCallingPermission(
            FlagBridgeContract.permission(context.packageName),
            "Only apps signed with the host's key may use the FeatureFlag bridge",
        )
        awaitStartup()
        return when (method) {
            FlagBridgeContract.METHOD_HELLO -> Bundle().apply {
                putInt(FlagBridgeContract.KEY_PROTOCOL, FlagBridgeContract.PROTOCOL)
            }
            FlagBridgeContract.METHOD_OVERRIDES -> overrides(context)
            FlagBridgeContract.METHOD_APPLY -> apply(context, extras)
            FlagBridgeContract.METHOD_SIGNAL -> Bundle().apply {
                putBoolean(FlagBridgeContract.KEY_HANDLED, FlagSignalChannel.host.deliver(arg.orEmpty()))
            }
            else -> throw IllegalArgumentException("Unknown bridge method '$method'.")
        }
    }

    override fun openFile(uri: Uri, mode: String): ParcelFileDescriptor {
        awaitStartup()
        val context = checkNotNull(context)
        if (uri.path != SCHEMA_PATH) throw FileNotFoundException("The bridge serves no file at $uri.")
        val file = File(FlagBridgeContract.schemaDirectory(context), FlagSchema.FILE_NAME)
        return ParcelFileDescriptor.open(file, ParcelFileDescriptor.MODE_READ_ONLY)
    }

    override fun query(
        uri: Uri,
        projection: Array<out String>?,
        selection: String?,
        selectionArgs: Array<out String>?,
        sortOrder: String?,
    ): Cursor? = null

    override fun getType(uri: Uri): String? = null

    override fun insert(uri: Uri, values: ContentValues?): Uri? = null

    override fun update(uri: Uri, values: ContentValues?, selection: String?, selectionArgs: Array<out String>?): Int = 0

    override fun delete(uri: Uri, selection: String?, selectionArgs: Array<out String>?): Int = 0

    /**
     * A cold-started host can receive its first call on a binder thread while `Application.onCreate`
     * is still running (S6). Once the main looper has run one task posted from here, `onCreate` has
     * returned, so the schema is published and every signal observer is registered.
     */
    private fun awaitStartup() {
        if (started) return
        if (Looper.myLooper() != Looper.getMainLooper()) {
            val ran = CountDownLatch(1)
            Handler(Looper.getMainLooper()).post { ran.countDown() }
            ran.await(startupTimeout.inWholeMilliseconds, TimeUnit.MILLISECONDS)
        }
        started = true
    }

    private fun overrides(context: Context): Bundle {
        val schema = schema(context) ?: return status(FlagBridgeContract.STATUS_NOT_PUBLISHED)
        val bytes = FlagPayload(acceptedOverrides(schema)).jsonBytes()
        if (bytes.size > FlagBridgeContract.MAX_PAYLOAD_BYTES) {
            return status(FlagBridgeContract.STATUS_TOO_LARGE).apply { putInt(FlagBridgeContract.KEY_SIZE, bytes.size) }
        }
        return status(FlagBridgeContract.STATUS_OK).apply { putByteArray(FlagBridgeContract.KEY_PAYLOAD, bytes) }
    }

    /**
     * Every stored override the schema accepts. The file belongs to the host, so its own code may
     * have left a value a strict import would reject; that value is left out rather than failing the
     * whole document. One pass drops every rejected key, so the second always decodes.
     */
    private fun acceptedOverrides(schema: FlagSchema): Map<FlagKey, FlagValueBox> {
        var values = schema.valueTypes.mapNotNull { (key, type) ->
            source.box(key, type)?.takeUnless { it.containsNonFiniteNumber }?.let { key to it }
        }.toMap()
        repeat(DECODE_ATTEMPTS) {
            val problems = try {
                FlagPayload.decode(FlagPayload(values).jsonBytes(), schema)
                return values
            } catch (rejected: FlagImportException.Rejected) {
                rejected.problems
            }
            values = values - problems.map { it.key }.toSet()
        }
        return values
    }

    private fun apply(context: Context, extras: Bundle?): Bundle {
        val schema = schema(context) ?: return status(FlagBridgeContract.STATUS_NOT_PUBLISHED)
        val payload = try {
            extras?.getByteArray(FlagBridgeContract.KEY_PAYLOAD)?.let { FlagPayload.decode(it, schema) }
        } catch (error: FlagImportException) {
            return rejected(error.message.orEmpty())
        }
        val removals = extras?.getStringArray(FlagBridgeContract.KEY_REMOVE).orEmpty().map(::FlagKey)
        val unknown = removals.filter { it !in schema.valueTypes }
        if (unknown.isNotEmpty()) return rejected(unknownRemovalMessage(unknown))

        val changes = LinkedHashMap<FlagKey, FlagValueBox?>()
        payload?.values?.let(changes::putAll)
        removals.forEach { changes[it] = null }
        try {
            source.setBoxes(changes)
        } catch (error: FlagException.UnsupportedValue) {
            // Strict import reads -1e400 as an infinity, which the store cannot hold. Nothing was written.
            return rejected(error.message.orEmpty())
        }
        return status(FlagBridgeContract.STATUS_OK)
    }

    private fun schema(context: Context): FlagSchema? = try {
        FlagSchema.read(FlagBridgeContract.schemaDirectory(context))
    } catch (ignored: FlagSchemaException) {
        // Missing, or unreadable: either way there is nothing to check overrides against.
        null
    }

    private fun status(status: String) = Bundle().apply { putString(FlagBridgeContract.KEY_STATUS, status) }

    private fun rejected(message: String) = status(FlagBridgeContract.STATUS_REJECTED).apply {
        putString(FlagBridgeContract.KEY_MESSAGE, message)
    }

    private fun unknownRemovalMessage(keys: List<FlagKey>): String {
        val names = keys.map { "'${it.rawValue}'" }
        val listed = if (names.size == 1) names.single() else names.dropLast(1).joinToString(", ") + " or " + names.last()
        val them = if (names.size == 1) "it" else "them"
        return "The host's schema has no flag $listed, so it cannot remove $them. Reconnect to load the current schema."
    }

    private companion object {
        val STARTUP_TIMEOUT = 10.seconds
        const val SCHEMA_PATH = "/schema"
        const val DECODE_ATTEMPTS = 2
    }
}
```

```kotlin
 * A host's bridge, in-process, for Robolectric. It speaks the protocol FlagBridgeProvider speaks,
 * over an in-memory map, and each test bends it to reach one status. Register it with
 * `Robolectric.buildContentProvider(FakeBridgeProvider::class.java).create(authority).get()`.

    var protocol: Int = FlagBridgeContract.PROTOCOL

    /** The published schema, or null for a host that never published. */
    var schema: FlagSchema? = null

    /** Served instead of [schema]'s bytes when set. */
    var schemaBytes: ByteArray? = null

    /** The overrides the host holds. */
    @Volatile
    var values: Map<FlagKey, FlagValueBox> = emptyMap()

    /** Signal names a host observer handles. */
    var handledSignals: Set<String> = emptySet()

    /** When set, every call answers with this status (and [forcedMessage]/[forcedSize]) instead. */
    var forcedStatus: String? = null
    var forcedMessage: String? = null
    var forcedSize: Int = 0

    /** How many calls throw DeadObjectException before one is answered, as a host that died would. */
    val deaths = AtomicInteger(0)

    /** When set, calls throw it, as the provider's own permission check does. */
    var refusal: SecurityException? = null

    /** When set, calls wait for it first, as a host stuck starting up does. */
    var stall: CountDownLatch? = null

    /** Every method called, in order, with its argument when it has one. */

        refusal?.let { throw it }
        if (deaths.getAndUpdate { if (it > 0) it - 1 else 0 } > 0) throw DeadObjectException()

            return status(status).apply {
                forcedMessage?.let { putString(FlagBridgeContract.KEY_MESSAGE, it) }
                putInt(FlagBridgeContract.KEY_SIZE, forcedSize)
            }

        return when (method) {
            FlagBridgeContract.METHOD_HELLO -> Bundle().apply { putInt(FlagBridgeContract.KEY_PROTOCOL, protocol) }
            FlagBridgeContract.METHOD_OVERRIDES -> overrides()
            FlagBridgeContract.METHOD_APPLY -> apply(extras)
            FlagBridgeContract.METHOD_SIGNAL -> Bundle().apply {
                putBoolean(FlagBridgeContract.KEY_HANDLED, arg in handledSignals)
            }
            else -> throw IllegalArgumentException("Unknown bridge method '$method'.")
        }

        calls.add("openFile ${uri.path}")

            FlagPayload.decode(checkNotNull(extras?.getByteArray(FlagBridgeContract.KEY_PAYLOAD)), schema)
        } catch (error: FlagImportException) {
            return status(FlagBridgeContract.STATUS_REJECTED).apply { putString(FlagBridgeContract.KEY_MESSAGE, error.message) }
        }
        val removals = extras?.getStringArray(FlagBridgeContract.KEY_REMOVE).orEmpty().map(::FlagKey)
        values = values + payload.values - removals.toSet()
        notifyObservers()
        return status(FlagBridgeContract.STATUS_OK)
    }

    private fun notifyObservers() {
        context?.contentResolver?.notifyChange(FlagBridgeContract.overridesUri(hostPackage), null)
    }

    private fun status(status: String) = Bundle().apply { putString(FlagBridgeContract.KEY_STATUS, status) }

    override fun query(
        uri: Uri,
        projection: Array<out String>?,
        selection: String?,
        selectionArgs: Array<out String>?,
        sortOrder: String?,
    ): Cursor? = null

    override fun getType(uri: Uri): String? = null

    override fun insert(uri: Uri, values: ContentValues?): Uri? = null

    override fun update(uri: Uri, values: ContentValues?, selection: String?, selectionArgs: Array<out String>?): Int = 0

    override fun delete(uri: Uri, selection: String?, selectionArgs: Array<out String>?): Int = 0

    private companion object {
        const val STALL_LIMIT_SECONDS = 10L
    }
```

Notes for the implementer. These are Robolectric facts, measured with 4.16 and SDK 36:
- **`SigningInfo` is shadowed.** Certificates must be set with `shadowOf(SigningInfo()).setSignatures(…)`. The API 35 public constructor's signers are ignored, and `apkContentsSigners` comes back empty.
- **`getInternalMutablePackageInfo(context.packageName)`** is how a test edits the companion's own `requestedPermissions` and signers.
- **Acquire never throws `SecurityException` under Robolectric.** `RefusingContentResolver`, a `ShadowContentResolver` subclass applied with `@Config(shadows = …)` on one test, makes it throw. So the acquire path does not need deferring to B4.
- **A provider's `DeadObjectException` propagates** through `ContentProviderClient.call`, so the retry is unit-testable. B4 pins the real thing as well.
- The two SHA-256 constants are the digests of the one-certificate signers `[1, 2, 3]` and `[4, 5, 6]`.

```kotlin
package com.andyyhope.featureflag.android.bridge

import android.content.ContentProviderClient
import android.content.ContentResolver
import android.content.Context
import android.content.pm.PackageInfo
import android.content.pm.PackageManager
import android.content.pm.Signature
import android.os.Build
import android.os.Bundle
import android.os.DeadObjectException
import android.os.ParcelFileDescriptor
import android.os.RemoteException
import com.andyyhope.featureflag.errors.FlagSchemaException
import com.andyyhope.featureflag.schema.FlagSchema
import com.andyyhope.featureflag.signals.FlagSignal
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.SupervisorJob
import kotlinx.coroutines.async
import kotlinx.coroutines.withTimeoutOrNull
import java.io.FileNotFoundException
import java.security.MessageDigest
import kotlin.time.Duration
import kotlin.time.Duration.Companion.seconds

/**
 * A companion's connection to one host app's FeatureFlag bridge.
 *
 * The companion needs `<uses-permission android:name="<hostPackage>.permission.FEATURE_FLAG_BRIDGE" />`
 * in its manifest, and must be signed with the host's key (or listed in its knownSigner permission).
 * Every operation acquires its own unstable provider client and closes it afterwards, so the
 * companion survives the host dying; a call that finds the host dead is retried once.
 */
public class FlagBridgeClient(
    context: Context,
    public val hostPackage: String,
    public val timeout: Duration = 5.seconds,
) {

    private val context: Context = context.applicationContext ?: context
    private val authority = FlagBridgeContract.authority(hostPackage)
    private val permission = FlagBridgeContract.permission(hostPackage)

    // Blocking binder calls run here, detached from the caller, so a timeout returns on time
    // even while the call itself is still waiting for the host.
    private val calls = CoroutineScope(SupervisorJob() + Dispatchers.IO)

    internal val resolver: ContentResolver get() = context.contentResolver

    /** Checks everything a companion needs, in the order it is worth fixing, and loads the host's schema. Never throws. */
    public suspend fun connect(): FlagBridgeConnection {
        val packageManager = context.packageManager
        val requested = packageInfo(packageManager, context.packageName, PackageManager.GET_PERMISSIONS)?.requestedPermissions
        if (requested == null || permission !in requested) return FlagBridgeConnection.UsesPermissionMissing(permission)
        packageInfo(packageManager, hostPackage, 0) ?: return FlagBridgeConnection.HostNotFound(hostPackage)
        if (context.checkSelfPermission(permission) != PackageManager.PERMISSION_GRANTED) return permissionDenied()
        return within(timeout) { handshake() } ?: FlagBridgeConnection.Unresponsive(hostPackage, timeout)
    }

    /** True when the host ran a handler for [signal]; false on no observer, timeout, or an unreachable host. Never throws. */
    public suspend fun send(signal: FlagSignal, timeout: Duration = this.timeout): Boolean = within(timeout) {
        try {
            perform { client -> client.call(FlagBridgeContract.METHOD_SIGNAL, signal.name, null) }
                ?.getBoolean(FlagBridgeContract.KEY_HANDLED) ?: false
        } catch (ignored: RemoteException) {
            false
        } catch (ignored: SecurityException) {
            false
        }
    } ?: false

    /**
     * Runs [operation] on a fresh unstable client for the host's provider and closes it. A
     * [DeadObjectException] means the host died mid-call; it is retried once with a new client,
     * which starts the host again. Returns null when the host has no provider. Blocking.
     */
    internal fun <T> perform(operation: (ContentProviderClient) -> T): T? {
        var attempt = 0
        while (true) {
            val client = resolver.acquireUnstableContentProviderClient(authority) ?: return null
            try {
                return operation(client)
            } catch (died: DeadObjectException) {
                if (++attempt == ATTEMPTS) throw died
            } finally {
                client.close()
            }
        }
    }

    /** One bridge method, blocking; the reply, or null when the host has no provider. */
    internal fun call(method: String, extras: Bundle? = null): Bundle? =
        perform { client -> client.call(method, null, extras) }

    private suspend fun <T : Any> within(timeout: Duration, block: () -> T): T? {
        val result = calls.async { block() }
        return withTimeoutOrNull(timeout) { result.await() }
    }

    private fun handshake(): FlagBridgeConnection = try {
        perform { client ->
            val protocol = client.call(FlagBridgeContract.METHOD_HELLO, null, null)?.getInt(FlagBridgeContract.KEY_PROTOCOL)
            if (protocol != FlagBridgeContract.PROTOCOL) {
                FlagBridgeConnection.Incompatible(
                    "The host speaks bridge protocol $protocol; this companion speaks ${FlagBridgeContract.PROTOCOL}. " +
                        "Update whichever app is older.",
                )
            } else {
                schema(client)
            }
        } ?: FlagBridgeConnection.BridgeNotInstalled(hostPackage)
    } catch (ignored: SecurityException) {
        permissionDenied()
    } catch (ignored: RemoteException) {
        // The host died twice in a row: as far as the companion can tell, it is not answering.
        FlagBridgeConnection.Unresponsive(hostPackage, timeout)
    }

    private fun schema(client: ContentProviderClient): FlagBridgeConnection = try {
        val descriptor = client.openFile(FlagBridgeContract.schemaUri(hostPackage), "r")
            ?: throw FileNotFoundException("The host served no schema.")
        val bytes = ParcelFileDescriptor.AutoCloseInputStream(descriptor).use { it.readBytes() }
        FlagBridgeConnection.Connected(FlagSchema.parse(bytes))
    } catch (ignored: FileNotFoundException) {
        FlagBridgeConnection.NotPublished
    } catch (error: FlagSchemaException) {
        FlagBridgeConnection.Incompatible(error.message.orEmpty())
    }

    private fun permissionDenied(): FlagBridgeConnection.PermissionDenied {
        val packageManager = context.packageManager
        return FlagBridgeConnection.PermissionDenied(
            hostPackage = hostPackage,
            hostCertificates = certificates(packageManager, hostPackage),
```

```kotlin
package com.andyyhope.featureflag.android.bridge

import android.database.ContentObserver
import android.os.Bundle
import android.os.Handler
import android.os.HandlerThread
import android.os.RemoteException
import com.andyyhope.featureflag.errors.FlagImportException
import com.andyyhope.featureflag.schema.FlagSchema
import com.andyyhope.featureflag.sources.FlagChange
import com.andyyhope.featureflag.sources.FlagChangeEmitter
import com.andyyhope.featureflag.sources.MutableFlagValueSource
import com.andyyhope.featureflag.transport.FlagPayload
import com.andyyhope.featureflag.values.FlagKey
import com.andyyhope.featureflag.values.FlagValueBox
import com.andyyhope.featureflag.values.FlagValueType
import kotlinx.coroutines.flow.Flow

/**
 * A live view of a host's companion overrides, for a companion's pole or editor.
 *
 * Reads come from an in-memory copy and never cross processes. The copy is refreshed when the
 * host's overrides change, which the host announces through a `ContentObserver` registered with
 * the system, so it keeps working when the host process dies and starts again. Writes are
 * blocking calls into the host: make them off the main thread. Close the source when done.
 */
public class FlagBridgeSource internal constructor(
    private val client: FlagBridgeClient,
    private val schema: FlagSchema,
    override val sourceName: String,
) : MutableFlagValueSource, AutoCloseable {

    private val emitter = FlagChangeEmitter()
    private val lock = Any()

    @Volatile
    private var cache: Map<FlagKey, FlagValueBox> = emptyMap()

    private val thread = HandlerThread("FlagBridgeSource").apply { start() }

    private val observer = object : ContentObserver(Handler(thread.looper)) {
        override fun onChange(selfChange: Boolean) {
            try {
                refresh()
            } catch (ignored: FlagBridgeException) {
                // The next change, or an explicit refresh, tries again.
            }
        }
    }

    init {
        client.resolver.registerContentObserver(FlagBridgeContract.overridesUri(client.hostPackage), false, observer)
        try {
            refresh()
        } catch (ignored: FlagBridgeException) {
            // Start empty; the companion shows the defaults until the host answers.
        }
    }

    override val changes: Flow<FlagChange> = emitter.changes

    /** From the in-memory copy; never a call into the host. */
    override fun box(key: FlagKey, type: FlagValueType): FlagValueBox? = cache[key]?.takeIf { it.matches(type) }

    /** Blocking IPC: one METHOD_APPLY. Call off the main thread. Throws [FlagBridgeException]. */
    override fun setBox(key: FlagKey, box: FlagValueBox?) {
        setBoxes(mapOf(key to box))
    }

    /** Blocking IPC: one METHOD_APPLY carrying every change, one host commit. Throws [FlagBridgeException]. */
    override fun setBoxes(changes: Map<FlagKey, FlagValueBox?>) {
        if (changes.isEmpty()) return
        val values = changes.entries.mapNotNull { (key, box) -> box?.let { key to it } }.toMap()
        val removals = changes.filterValues { it == null }.keys.map { it.rawValue }.toTypedArray()
        val bytes = FlagPayload(values).jsonBytes()
        if (bytes.size > FlagBridgeContract.MAX_PAYLOAD_BYTES) {
            throw FlagBridgeException.TooLarge(bytes.size, FlagBridgeContract.MAX_PAYLOAD_BYTES)
        }
        val extras = Bundle().apply {
            putByteArray(FlagBridgeContract.KEY_PAYLOAD, bytes)
            putStringArray(FlagBridgeContract.KEY_REMOVE, removals)
        }
        val reply = request(FlagBridgeContract.METHOD_APPLY, extras)
        if (reply.getString(FlagBridgeContract.KEY_STATUS) != FlagBridgeContract.STATUS_OK) throw failure(reply)
        val changed = synchronized(lock) {
            val updated = cache.toMutableMap()
            val changed = changes.filter { (key, box) -> updated[key] != box }.keys
            changes.forEach { (key, box) -> if (box == null) updated.remove(key) else updated[key] = box }
            cache = updated
            changed
        }
        if (changed.isNotEmpty()) emitter.emit(FlagChange.Keys(changed))
    }

    /** Blocking IPC: re-reads the host's overrides; emits [FlagChange.All] when anything differs. Throws [FlagBridgeException]. */
    public fun refresh() {
        val reply = request(FlagBridgeContract.METHOD_OVERRIDES)
        if (reply.getString(FlagBridgeContract.KEY_STATUS) != FlagBridgeContract.STATUS_OK) throw failure(reply)
        val values = decode(reply.getByteArray(FlagBridgeContract.KEY_PAYLOAD))
        val changed = synchronized(lock) {
            (values != cache).also { cache = values }
        }
        if (changed) emitter.emit(FlagChange.All)
    }

    /** Unregisters the ContentObserver and stops its thread. */
    override fun close() {
        client.resolver.unregisterContentObserver(observer)
        thread.quitSafely()
    }

    private fun request(method: String, extras: Bundle? = null): Bundle = try {
        client.call(method, extras) ?: throw FlagBridgeException.Unavailable(null)
    } catch (error: RemoteException) {
        throw FlagBridgeException.Unavailable(error)
    } catch (error: SecurityException) {
        throw FlagBridgeException.Unavailable(error)
    }

    /** The exception for a reply whose status is not [FlagBridgeContract.STATUS_OK]. */
    private fun failure(reply: Bundle): FlagBridgeException {
        val status = reply.getString(FlagBridgeContract.KEY_STATUS)
        return when (status) {
            FlagBridgeContract.STATUS_REJECTED -> FlagBridgeException.Rejected(reply.getString(FlagBridgeContract.KEY_MESSAGE).orEmpty())
            FlagBridgeContract.STATUS_NOT_PUBLISHED -> FlagBridgeException.NotPublished()
            FlagBridgeContract.STATUS_TOO_LARGE ->
                FlagBridgeException.TooLarge(reply.getInt(FlagBridgeContract.KEY_SIZE), FlagBridgeContract.MAX_PAYLOAD_BYTES)
            else -> FlagBridgeException.Unavailable(IllegalStateException("The host answered with the unknown status '$status'."))
        }
    }

    // Rejected carries the import message as its reason; it has no cause to chain.
    @Suppress("SwallowedException")
    private fun decode(bytes: ByteArray?): Map<FlagKey, FlagValueBox> {
        val payload = bytes ?: throw FlagBridgeException.Unavailable(IllegalStateException("The host answered ok without a payload."))
        return try {
            FlagPayload.decode(payload, schema).values
        } catch (error: FlagImportException) {
            // The host's overrides no longer fit this companion's copy of its schema: reconnect.
            throw FlagBridgeException.Rejected(error.message.orEmpty())
        }
    }
}
```

## Contract issues found

Each item is something the contract gets wrong, leaves open, or cannot do as written. The closest faithful version is what this plan implements. None renames a contract name.

1. **`enforceCallingPermission` refuses every caller in the provider's own process** (measured on API 36).
   - `ContextImpl.checkCallingPermission` returns `PERMISSION_DENIED` when the calling pid is the provider's own pid, so the call throws `SecurityException: … uid N does not have <permission>` even though the app holds the permission.
   - Consequences:
     - B4 *must* run the provider in `:host`; B4 Step 2 records this as its red step.
     - A host can never use `FlagBridgeClient` against its own provider, for example from an in-app debug screen.
   - `enforceCallingOrSelfPermission` would admit the host itself. The plan keeps the contract's call; decide in M3 or M4 whether a host-side screen needs the bridge.
   - Robolectric does not reproduce this: it consults its granted-permission set, so B1's unauthorised-call test runs there.
2. **The overview's deviation 4 names a property that does not exist.** It says the ART check uses "the public `FlagDefaultComparison.description`", but `FlagDefaultComparison` (M1) has no `description`; its public description is `toString()`, which B4 calls.
3. **`connect()` cases the contract does not cover:**
   - A `DeadObjectException` on the retry as well gives `Unresponsive(hostPackage, timeout)`.
   - A `SecurityException` from the provider's own `call()` check, as opposed to from acquire, gives `PermissionDenied`.
   - The timeout covers acquire, `hello` and the schema read together, not `hello` alone. The schema read is a binder call too, and a separate budget for it would double the worst case.
4. **`withTimeoutOrNull(timeout)` alone cannot time out a binder call.** `withContext(Dispatchers.IO) { blockingCall() }` is not cancellable mid-call, so `withTimeoutOrNull` would return only after the host answered. The client instead runs the call in a detached `async` on a client-owned `CoroutineScope(SupervisorJob() + Dispatchers.IO)` and awaits that with the timeout. The stuck call is abandoned and finishes on its own; B2's timing assertions pin this.
5. **`FlagBridgeSource` statuses the contract does not cover:**
   - An unknown status, or `ok` with no payload, gives `Unavailable(IllegalStateException(…))`.
   - No provider (a null client or reply) gives `Unavailable(null)`.
   - `ok` with a payload that fails `FlagPayload.decode(payload, schema)` gives `Rejected(e.message)`. This happens when the host republished a different schema after `connect()`. `Rejected`'s text ("The host rejected the change: …") reads oddly for a read; a dedicated subclass, or reconnecting, would be better. That needs a contract change.
6. **`client.source(schema)` blocks.** The contract runs one `refresh()` during construction, which is a binder call, but the function is not `suspend`. Its KDoc now says to call it off the main thread. M3 must do so.
7. **The provider treats an unreadable schema like a missing one.** The contract says "no schema → `STATUS_NOT_PUBLISHED`". The provider catches every `FlagSchemaException`, `Malformed` included, because an exception Binder cannot parcel would crash the host's binder thread. `connect()` still reports a malformed file as `Incompatible`, because it parses the bytes itself.
8. **The unknown-removal message is not in the contract.** B1 fixes it, as given in B1's Interfaces.
9. **`apply` must also catch `FlagException.UnsupportedValue`.** The contract maps only `FlagImportException` to `STATUS_REJECTED`. M2a's `setBoxes` refuses a non-finite double with `UnsupportedValue`, and strict import lets one through (`-1e400`). Uncaught, it would throw out of `call()` on the host's binder thread. B1 maps it to `STATUS_REJECTED` with its message (`aNonFiniteNumberIsRejectedNotThrown`). This is the item M2a's "Contract issues found" 2 hands to B1.
10. **`overrides` drops keys whose stored box is non-finite before encoding.** `FlagPayload.jsonBytes()` would otherwise throw `NonFiniteNumber`, and a host's own `putFloat(NaN)` would break the whole document. This is Review Focus 2, beyond the contract's "encode, decode, drop and repeat", which never reaches the decode in that case.
11. **Robolectric limits:**
    - `SigningInfo` is shadowed, so certificates are set through `ShadowSigningInfo.setSignatures`.
    - Acquire never throws `SecurityException`, so a `ShadowContentResolver` subclass forces it.
    - Neither needed deferring to B4. B4 adds the real `DeadObjectException` (a host killed mid-call) and the real barrier, which Robolectric can only approximate.
12. **For M2a (outside this plan):** with the stand-in `SharedPreferencesSource`, lint reports one `ApplySharedPref` warning on the deliberate `commit()`. A real A4 may want `@SuppressLint("ApplySharedPref")` with a comment. The warning does not fail the build.
